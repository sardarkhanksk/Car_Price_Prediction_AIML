# **Car Price Prediction using Advanced Machine Learning**  

## 📌 Overview  
This project aims to predict the price of a car based on various attributes like mileage, model, brand, year of registration, color, and more. Using advanced machine learning techniques, we preprocess data, engineer features, select the most relevant ones, and build multiple predictive models to determine the most accurate approach.  

---  

## 🚀 Key Features & Workflow  

### 🔹 **1. Data Processing & Preprocessing**  
- Handled missing values, outliers, and noise for reliable predictions.  
- Encoded categorical variables to numerical representations.  
- Scaled features and split data for training and evaluation.  

### 🔹 **2. Feature Engineering & Selection**  
- Created **polynomial features** to capture complex relationships.  
- Applied **Recursive Feature Elimination (RFE)** and **Principal Component Analysis (PCA)** for dimensionality reduction.  

### 🔹 **3. Model Building & Optimization**  
- Implemented **Linear Regression, Random Forest, and Boosted Trees** for predictions.  
- Used **Grid Search** to optimize hyperparameters for the top models.  
- Combined top-performing models using an **ensemble approach** for better generalization.  

### 🔹 **4. Model Evaluation & Analysis**  
- Assessed models using **cross-validation** for robustness.  
- Analyzed **true vs predicted values** to understand model performance.
